A marketing site for a custom home builder based in South Lake Tahoe, showcasing his portfolio of modern cabin-style luxury homes. Built on Middleman with a Bootstrap 4 foundation, and a few interactive bits sprinkled in as React components. JavaScript was bundled with esbuild — a big speed jump over the Sprockets/Parcel setups I'd been using on earlier Middleman projects.
